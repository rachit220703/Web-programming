VALERION STAYZ — STATIC WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/ (cropped photos from the Instagram screenshots supplied in the chat)

HOW TO RUN:
1. Extract the ZIP file.
2. Open the Valerion_Stayz_Website folder.
3. Double-click index.html.
4. The website opens in your browser. No server, Python, database or installation is required.

EDITING:
- Change text, room descriptions and links in index.html.
- Change colours, fonts and layout in style.css.
- Change interactions in script.js.
- Replace photos inside assets/ with original high-resolution property photos, keeping the same filenames.

IMPORTANT:
- Prices, exact address, occupancy, policies and room-specific inclusions were not provided, so the website asks visitors to contact the owner instead of inventing details.
- The supplied Instagram screenshots were cropped to create initial image assets. Replace them with original photos for a sharper public website.
- The two contact numbers and Instagram profile were taken from the supplied profile screenshot.
- Google Fonts require an internet connection; fallback fonts are provided.
